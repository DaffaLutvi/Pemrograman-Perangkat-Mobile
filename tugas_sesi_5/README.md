# NusaEvent Hub

Aplikasi Flutter Material 3 untuk menjelajahi seminar dan workshop, melihat
galeri poster serta denah venue, dan mengelola pendaftaran tiket.

## Fitur

- Daftar acara interaktif dengan filter AI, Mobile, IoT, dan Cybersecurity.
- Galeri poster responsif dan denah venue yang dapat digeser serta diperbesar.
- Form pendaftaran dengan validasi nama, NIM, email, WhatsApp, pilihan peserta,
  tanggal kehadiran, seminar kit, donasi, dan persetujuan tata tertib.
- Tiket aktif dengan dialog konfirmasi sebelum pembatalan.

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```

Untuk menjalankan pemeriksaan kode dan tes widget:

```bash
flutter analyze
flutter test
```
